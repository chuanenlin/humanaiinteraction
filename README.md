# Human-AI Interaction: labs

Colab notebooks and a web app template for the labs in [Human-AI Interaction](https://humanaiinteraction.com). Students can open them from the course schedule, then save a copy to their Drive (File, then Save a copy in Drive) before they run them. The saved outputs are from one run of each notebook, so the results of running one again will be a little different.
